**JewPeter** is a premium, galaxy-themed stock market forecasting application. It leverages machine learning to provide intelligent price predictions wrapped in a stunning, celestial interface.

---

## ✨ Features

- **Celestial Dashboard**: A high-end "Subtle Space" UI with parallax starfields and deep-space nebulas.
- **AI Forecasting**: Powered by an optimized **XGBoost** model that analyzes historical variance and technical indicators (RSI, MACD, etc.).
- **Smart Search**: Integrated autocomplete ticker search using the Yahoo Finance API.
- **Flexible Horizons**: Forecast stock trajectories for **1 Week, 2 Weeks, 1 Month, or 6 Months**.
- **Interactive Visualization**: Real-time charts comparing actual historical data with ML-generated predictions.

---

## 🛠️ Tech Stack

### Frontend
- **React.js** (Vite)
- **Recharts** (Interactive Data Viz)
- **Lucide Icons**
- **Vanilla CSS** (Custom Galaxy Design System)

### Backend
- **FastAPI** (High-performance Python)
- **XGBoost** (Machine Learning Model)
- **yfinance** (Financial Data Engine)
- **Pandas-TA** (Technical Analysis Library)

---

## 🚀 Deployment

The project is configured for automated dual-deployment:
- **Frontend**: Hosted on **GitHub Pages**.
- **Backend**: Hosted on **Render** (Python Web Service).
